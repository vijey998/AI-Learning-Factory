# 13. Probe hidden representations

Status: executable CPU reference. Chapter: CH-74.

## Run

`python code/milestone_labs.py --lab 13`

CPU toy model; GPU optional.

Collect activations with controlled data splits and train a small probe.

Use held-out data, a random-label baseline and an intervention; do not equate probe accuracy with mechanism.

## Required experiment record

Environment and revision; input data and licenses; shape/dtype; seeds; correctness checks; warmup and synchronization; elapsed time and memory; measured vs estimated quantities; failures; next experiment.
